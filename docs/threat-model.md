# Threat Model

NEPRA separates a formal inference-time mechanism from an empirical identity
attack benchmark.

## Protected Release

| Field | Definition |
|---|---|
| Protected asset | One standardized tangent-space EEG trial vector |
| Protected phase | Held-out session and future inference releases |
| Public data | The complete calibration session |
| Adversary view | Released vector and all mechanism parameters |
| Trust boundary | Randomization occurs before the vector leaves the client |
| Adjacency | Replace one clipped trial vector with another |
| Sensitivity | At most `2C` after L2 clipping to norm `C` |
| Formal mechanism | Isotropic analytic Gaussian randomization |
| Privacy unit | One trial |

The claim is conditional on preprocessing being frozen from public calibration
data and on every protected release using fresh secret randomness.

## Empirical Attack Benchmark

The empirical adversary performs closed-set identification among the nine
enrolled subjects. It knows the feature pipeline and perturbation family.

Two attacker-training regimes are evaluated:

1. **Clean auxiliary attacker:** trained on clean public calibration features.
2. **Mechanism-aware attacker:** trained on independently perturbed public
   calibration features generated by the same mechanism.

Logistic regression, RBF SVM, random forest, and a compact MLP are compared.
The strongest held-out identity result is reported. Poor performance by these
models is evidence limited to this attack suite, not a formal privacy guarantee.

## Explicit Non-Goals

NEPRA v0.1 does not claim:

- user-level or session-level differential privacy;
- privacy under repeated-release composition;
- EEG anonymization or pseudonymization;
- protection from membership or attribute inference;
- open-set recognition resistance;
- clinical or production readiness.
